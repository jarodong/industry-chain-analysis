# industry-chain-analysis

产业链全景及关键节点分析 Skill —— 一套面向国资产业投资集团的产业链研究方法论，帮助在投资研究早期通过产业链视角判断行业或标的是否值得继续研究。可直接作为 Claude Code Skill 使用。

## 这是什么

本 Skill 解决的核心问题：**国资平台做投资研究时，容易被项目叙事带偏——盯着财务数据、估值和退出路径算账，却忘了先判断标的在产业链中处于什么位置、是不是关键节点、利润最终流向谁。**

它用一套标准化的研究流程，强制将分析从"项目思维"拉回到"产业思维"。

## 核心方法论

### 一句话标准

> 先做产业判断，再做标的判断。产业判断决定"应不应该在这个环节布局"，标的判断决定"这个标的值不值得投"。两个判断都成立，才是国资平台应该参与的项目。

### 双路径架构

| 路径 | 适用场景 | 步骤数 |
|------|---------|--------|
| **主路径：标的研判** | 客户推了标的/领导快问行业 | 6步 |
| **副路径：行业研究** | 系统研究一个产业，为招商/布局做准备 | 8步 |

### 三级研究强度

| 强度 | 适用场景 | 输出重点 |
|------|---------|---------|
| **L1 快速判断** | 领导临时询问、会议前准备 | 一句话结论、产业链简图、3条风险 |
| **L2 标准研判** | 客户推标的、项目初筛、内部讨论 | 行业分类、流程图、标的定位、材料验证、关键节点、利润归属 |
| **L3 完整研究** | 系统行业研究、产业图谱、项目库建设 | 多口径分类、完整图谱、代表企业、生命周期、需求驱动、观察清单 |

### 五项核心原则

1. **先行业，后标的**——不能一上来就相信客户材料里的企业叙事
2. **先产业链位置，后企业优劣**——企业好不好，不能脱离产业链判断
3. **关键节点 ≠ 利润点**——一个环节很重要，不代表它赚钱
4. **不被材料叙事带偏**——客户PPT是研究对象，不是研究结论
5. **结论服务下一步动作**——输出"是否值得继续研究"，不输出"是否投资"

### 客户材料反向拆解

针对客户PPT、商业计划书、券商报告中常见的9种美化手法，Skill内置了反向验证机制：

- 用大行业空间掩盖小细分市场
- 用行业高增长掩盖企业低增长
- 用技术概念掩盖产品低壁垒
- 用可比公司估值掩盖标的差异
- 用IPO案例掩盖退出不确定性
- 用"全球领先""国内第一"等模糊表述替代可验证指标

## V1.0 的迭代基础

本 Skill 不是凭空编写的模板，而是基于三个真实案例的完整研究和反复迭代：

1. **社区养老**——非标准行业，行业分类困难，验证了"概念层级确认"前置步骤的必要性
2. **康养产业**——跨行业概念，边界模糊，验证了"概念关系图"和"商业模式分组"的价值
3. **光通信 + 具体投资标的**——标准行业 + 客户PPT，验证了"材料反向拆解"和"标的研判路径"的实战效果

三个案例覆盖了非标准行业、跨行业概念、标准行业三种典型场景。

## 适用场景

- 客户/中介推来一个标的，需要快速判断"能不能继续看"
- 领导突然问"某某行业怎么看"，半天内要给出判断框架
- 系统研究一个产业，为招商、基金布局或项目库建设做准备
- 拿到一份投融资PPT/商业计划书/券商材料，需要识别其中的包装和美化
- 判断一个标的在产业链中是否处于关键位置、是否具备利润留存能力

## 安装方法

### 方式一：Git Clone（推荐）

```bash
git clone https://github.com/jarodong/industry-chain-analysis.git \
  ~/.claude/skills/industry-chain-analysis
```

重启 Claude Code 后，Skill 自动生效。

### 方式二：手动复制

将 `SKILL.md` 文件复制到 `~/.claude/skills/industry-chain-analysis/` 目录即可。

## 使用方法

安装后，在 Claude Code 中提到以下关键词时自动触发：

- "分析某某行业"
- "产业链怎么看"
- "这个标的能不能投"
- "某某行业的瓶颈在哪里"
- "某某行业适合国资参与吗"
- "产业链全景及关键节点分析"

### 推荐配套工具

- **企业查询MCP**（企查查/天眼查/爱企查）：用于标的真实性验证、股权穿透、本地企业摸底、风险筛查
- **文档读取MCP**：用于直接读取客户PPT/PDF等材料

### 调用示例

```
# 标的研判（最常用）
请使用产业链全景及关键节点分析Skill V1，对以下标的进行研究。请输出行业分类、产业链Mermaid流程图、标的定位图、客户材料反向验证、关键节点判断、利润归属判断和后续研究问题清单。

# 行业快研
请对XX行业做一次L1行业快研。重点是让我快速形成行业整体概念，请输出Mermaid产业链总览图。

# 完整研究
请对XX行业做一次L3完整研究。请先确认行业分类和研究边界，再输出完整报告。
```
